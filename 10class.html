Теория по геометрии для 10 класса

Аксиомы стереометрии

1.Для любой плоскости пространства существует точка, ей не принадлежащая.

2.В любой плоскости пространства выполняются все аксиомы планиметрии.

3.Через любые три точки пространства, не принадлежащие одной прямой, проходит плоскость и притом только одна.

4.Если две точки прямой принадлежат плоскости, то и вся прямая принадлежит этой плоскости.

5.Если две плоскости имеют общую точку, то они пересекаются по прямой.

6.Расстояние между любыми двумя точками пространства одинаково для любой плоскости, проходящей через эти точки.
